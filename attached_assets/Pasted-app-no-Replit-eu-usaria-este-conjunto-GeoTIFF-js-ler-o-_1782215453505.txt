Remover suavização excessiva do terreno 3D.

Não usar:

- Bicubic interpolation
- Bilinear interpolation excessiva
- Smooth terrain
- Simplify geometry

Preservar mudanças abruptas de altitude (breaklines).

Aplicar suavização adaptativa:

- Diferenças pequenas (<1m): suavizar
- Diferenças médias (1–3m): suavizar pouco
- Diferenças grandes (>3m): não suavizar

Preservar taludes, bermas, cortes e escavações.

Adicionar fator de exagero vertical configurável (1x–5x).

Código para substituir a suavização atual:

function suavizacaoAdaptativa(
altura,
largura,
alturaRaster
){

let resultado=
new Float32Array(
altura.length
);

for(
let y=1;
y<alturaRaster-1;
y++
){

for(
let x=1;
x<largura-1;
x++
){

const i=
y*largura+x;

const centro=
altura[i];

const vizinhos=[

altura[i-1],
altura[i+1],

altura[i-largura],
altura[i+largura]

];

const media=

vizinhos.reduce(
(a,b)=>a+b
)/4;

const diferenca=
Math.abs(
centro-media
);

if(
diferenca<1
){

resultado[i]=
(centro+media)/2;

}

else if(
diferenca<3
){

resultado[i]=
centro*0.8+
media*0.2;

}

else{

resultado[i]=
centro;

}

}

}

return resultado;

}

Esse código faz:

ruído pequeno → suaviza
terreno normal → suaviza pouco
talude → preserva
