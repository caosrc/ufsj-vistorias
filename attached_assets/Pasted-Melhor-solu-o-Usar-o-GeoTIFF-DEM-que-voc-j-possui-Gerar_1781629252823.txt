Melhor solução

✅ Usar o GeoTIFF (DEM) que você já possui

✅ Gerar as curvas de nível no próprio servidor do Replit

✅ Usar API apenas para complementar altitudes quando não existir TIF

Isso é mais rápido, mais preciso e não depende de limites de APIs. A própria comunidade GIS recomenda gerar curvas diretamente a partir de um DEM usando ferramentas GIS, em vez de tentar obter curvas prontas de serviços online.

APIs gratuitas recomendadas
1. Open-Elevation

Ideal para:

Consultar altitude de um ponto
Perfil de terreno

Limite gratuito disponível.

Código JavaScript
async function obterAltitude(lat, lon) {
  const url =
    `https://api.open-elevation.com/api/v1/lookup?locations=${lat},${lon}`;

  const res = await fetch(url);
  const data = await res.json();

  return data.results[0].elevation;
}

Uso:

const altitude = await obterAltitude(
  -20.530,
  -44.063
);

console.log(altitude);
2. OpenZenith

Sem chave API.

Possui:

Elevação
Perfil
Terreno global

Utiliza dados Copernicus/SRTM.

Código
async function getElevation(lat, lon) {

  const response = await fetch(
    `https://openzenith.cyopsys.com/api/elevation?lat=${lat}&lon=${lon}`
  );

  const data = await response.json();

  return data.elevation;
}

Gerar curvas

Instale:

npm install marchingsquares

Código:

import { isoLines } from 'marchingsquares';

const curvas = isoLines(
  matrizElevacao,
  1000
);

Onde:

1000

é a curva de 1000 metros.

Converter para GeoJSON
const geojson = {
  type: "FeatureCollection",
  features: curvas.map(line => ({
    type: "Feature",
    properties: {
      elevation: 1000
    },
    geometry: {
      type: "LineString",
      coordinates: line
    }
  }))
};
Mostrar no Leaflet
L.geoJSON(geojson, {

  style: {
    color: '#663300',
    weight: 1
  }

}).addTo(map);
